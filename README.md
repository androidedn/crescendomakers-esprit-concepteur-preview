# Aperçu public — Esprit Concepteur, Module 1

Ce dépôt contient uniquement l’aperçu statique du tunnel de présentation du Module 1 d’Esprit Concepteur.

Il contient la maquette et les documents destinés aux visiteurs, sans l’historique,
les documents de gouvernance ni les sources pédagogiques de travail du dépôt privé.

Identité actuelle : la composition illustrée est la signature visuelle CrescendoMakers ;
le logo compact coloré à deux arcs, carnet, plume et pièce de puzzle unique est utilisé
dans le header. Aucun histogramme. Le logo Esprit Concepteur reste distinct.

Les formulaires et le paiement restent des démonstrations, pas une vente réelle.

Illustrations de marque proposées : atelier avec motif numérique fictif, clarification,
échanges et accompagnement avec personnages ; carnets annotés de notes fictives.
Les scènes sont réutilisables et ne représentent ni un vrai témoignage ni le contenu du cours.
Sources et variantes conservées dans le dépôt privé. La proposition de nouveau logo
Esprit Concepteur n'est pas publiée ici avant approbation.

La publication GitHub Pages est déclenchée lors d’un envoi sur `main`.
